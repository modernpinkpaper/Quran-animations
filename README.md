# Quran animations

Short (about 1 minute) vertical Quran teaching videos with the emotional robots. Quran only, simple English, one easy thing to do.
Start with `CLAUDE.md` and `menu/START_HERE.md`. The three script types and the formula are in `menu/formats/religious_teaching.md`. Reference videos are in `videos/` (start from `videos/rumor/`).
Set up the voices once with `voices/setup_chatterbox.sh`. Render with Chromium (Playwright) and ffmpeg.
